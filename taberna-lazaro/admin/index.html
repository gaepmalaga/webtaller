¿De dónde saco la llave? (2 minutos, una sola vez)
  1. Entra en github.com → llaves de acceso.
  2. Nombre: Panel Taberna Lázaro.
  3. Repository access → Only select repositories → marca gaepmalaga/webtaller.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token y copia lo que salga. Es la única vez que se ve.

Solo sirve para este repositorio. Se guarda en este navegador y únicamente viaja a GitHub. Si pierdes el móvil, la borras allí y deja de valer.
