Entrar

Para poder guardar cambios hace falta una llave de GitHub. Se pide una vez y se queda guardada en este navegador: no se manda a ningún sitio que no sea GitHub.

Cómo se saca la llave (2 minutos, una sola vez)
  1. Entra en github.com → llaves de acceso (hay que tener la sesión iniciada).
  2. Ponle un nombre: Panel Taberna Lázaro.
  3. En Repository access, elige Only select repositories y marca gaepmalaga/webtaller.
  4. En Permissions → Repository permissions, busca Contents y ponlo en Read and write.
  5. Dale a Generate token y copia lo que salga (empieza por github_pat_). Es la única vez que se ve.

Esa llave solo sirve para este repositorio y caduca cuando tú digas. Si alguna vez se pierde el móvil, se borra desde la misma página de GitHub y deja de valer.
